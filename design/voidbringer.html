VOIDBRINGER

Voidbringer on its own, as a standalone plugin. The sound and all 16 presets stay exactly the same and so does the black hole's shape. Only the look changed: black, red instead of violet, same fonts as before, and its own name only. Every control works, and the preset arrows load the real preset values.

  • NAMEHeader says only VOIDBRINGER and "by sonicsystems", with voidbringer's own mark.
  • REDPure black window like before. Red is now the only colour on the controls, buttons, tabs and meter.
  • KNOBSEach knob is a small event horizon: a black core, a glowing red arc for the value and a pale dot as pointer.
  • FONTSSame JetBrains Mono as before.
  • BLACK HOLESame shape and motion. Its colour follows the sound: a clean patch glows white, more FM, feedback and drive turn it red.
